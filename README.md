### En producción

**[AgendaIO](https://coddily.com/works/agendaio)** — SaaS de reservas y cobros para negocios de servicios ([agenda-io.com](https://agenda-io.com)).
Página de reservas para cada negocio, disponibilidad calculada en cada consulta con control de
concurrencia en PL/pgSQL, cobros con tarjeta y SINPE Móvil, WhatsApp automático, Google Calendar
y app del panel para Android y Windows en Flutter.
<sub>React · Node.js · Express · PostgreSQL · Supabase · Flutter · Firebase</sub>

**[Agromag Ventas](https://coddily.com/works/agromag-ventas)** — Punto de venta e inventario a la medida para un agroservicio y clínica veterinaria.
Ventas desde el celular o la caja, inventario que se descuenta al instante, comprobantes y cierre
del día por método de pago y por empleado. Corre en el servidor del cliente con HTTPS y respaldos automáticos.
<sub>Astro · Node.js · PostgreSQL</sub>

**[Okuru](https://coddily.com/works/okuru)** — App para pasar archivos y textos entre tus dispositivos por WiFi, sin nube ni cuenta.
Descubrimiento automático en la red, emparejamiento con X25519, envío cifrado de extremo a extremo
por internet e integración nativa en Windows y Android.
<sub>Flutter · Dart · Kotlin · C++</sub>
